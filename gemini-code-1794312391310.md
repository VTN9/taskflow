# Product Requirement Document (PRD)

## 1. Visión del Producto
**Nombre sugerido:** TaskFlow / FocusApp  
**Propósito:** Aplicación web de gestión de tareas moderna, minimalista y colaborativa que permite organizar la vida personal y profesional con control total del usuario, micro-interacciones fluidas, soporte offline/local y compartición en tiempo real desplegada en **Vercel**.

---

## 2. Stack Tecnológico & Arquitectura Recomendada

| Capa | Tecnología | Justificación |
| :--- | :--- | :--- |
| **Hosting & Deploy** | **Vercel** | Despliegue en la nube rápido, optimizado para React y soporte sin servidor (Serverless). |
| **Framework Frontend** | **React 19** (o **Next.js 15+ App Router**) | Manejo de UI reactiva con Server Actions y funciones Edge para peticiones ultrarrápidas. |
| **Estilos CSS** | **Tailwind CSS v4** | Utilidades modernas para una interfaz limpia, responsive y fácil de personalizar. |
| **Componentes UI** | **shadcn/ui + Radix UI** | Accesibilidad nativa, estética minimalista y componentes *friendly* como desplegables modernos (*dropdowns*, *popovers*). |
| **Iconografía** | **Lucide React** | Iconos limpios, consistentes y ligeros. |
| **Drag & Drop** | **@dnd-kit/core** & `@dnd-kit/sortable` | Solución accesible y fluida para reordenar tareas visualmente sin usar flechas. |
| **Persistencia Cloud** | **Vercel KV / Upstash Redis** o **Supabase (JSONB)** | Almacenamiento JSON en la nube ligero sin backend tradicional, necesario para compartir enlaces en vivo. |
| **Notificaciones** | **Web Notifications API + Sonner (shadcn)** | Alertas nativas en el navegador y avisos visuales (*toasts*) dentro de la app. |

---
